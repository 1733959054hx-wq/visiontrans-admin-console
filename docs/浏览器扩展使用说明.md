# 浏览器扩展使用说明（Chrome / Edge）

> 视界译管理控制台的浏览器扩展形态，与网页版是**同一套前端代码的两种打包方式**：
> 管理端与商户端页面、统一登录、验证码等功能完全一致。
> 本文档面向团队成员本地安装使用，不需要上架应用商店。

---

## 一、它和直接开网页有什么区别

| 项 | 网页版（主用） | 浏览器扩展 |
|---|---|---|
| 入口 | 浏览器输入 `http://localhost:5173`（开发）或部署地址 | 点工具栏图标，新标签页打开完整后台 |
| 后端地址 | 相对路径 `/api`（同域或 Vite 代理） | 首次打开时手动填写，可随时指向任意可访问的后端 |
| 浏览器保存密码 | 支持 | **不支持**（Chrome 安全限制：密码管理器不对 `chrome-extension://` 页面生效） |
| 登录态 | localStorage | 同样保存在扩展本地，8 小时内重开浏览器免登录 |
| 联网要求 | 后端可访问即可 | 同左，且后端已放行扩展跨域来源 |

> 日常使用推荐网页版；扩展适合需要固定图标入口、或要把前端指向远程后端演示的场景。

## 二、构建扩展（每次代码更新后执行）

前置：已安装 Node.js 18+，并在 `admin-front/` 下执行过 `npm install`（扩展构建**没有引入任何额外依赖**）。

```bash
cd admin-front
npm run build:ext
```

产物输出到 `admin-front/dist-extension/`（该目录已加入 `.gitignore`，不需要提交，每人本地构建）。
构建会自动重新生成 `extension/icons/` 下的扩展图标。

## 三、在浏览器中加载

### Chrome

1. 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择文件夹：`admin-front/dist-extension`
4. 工具栏出现视界译图标即成功（建议点固定图标）

### Edge

步骤相同，地址改为 `edge://extensions`，选择「加载解压缩的扩展」。

## 四、首次使用：配置后端地址

1. 点击工具栏上的扩展图标，自动在新标签页打开；
2. 首次进入会落到「连接服务器」配置页：
   - **本机联调**：保持默认 `http://localhost:8080`（系统会自动补全 `/api`）；
   - **连接他人/服务器上的后端**：填对应地址，如 `http://192.168.1.20:8080`（对端后端必须正在运行且网络可达）；
3. 点「保存并前往登录」，用正常账号登录：
   - 管理员 `admin / admin123`
   - 商户 `merchant / merchant123`

地址仅保存在扩展本地（localStorage），不会上报。

## 五、更新扩展（代码有变更时）

1. 重新执行 `npm run build:ext`；
2. 打开 `chrome://extensions`，找到本扩展卡片，点刷新图标（圆形箭头）；
3. 重新点击扩展图标打开即可。

## 六、常见问题

| 现象 | 原因与处理 |
|---|---|
| 打开后停在配置页 | 尚未配置后端地址，填写可访问的后端地址即可 |
| 登录提示网络异常 / 请求失败 | 后端没启动，或填写的地址不可达；本机确认 8080 端口、远程确认 IP 与防火墙 |
| 控制台看到 CORS / 跨域报错 | 后端 CORS 白名单已含 `chrome-extension://*`（见 `application.properties`）；若仍报错，确认运行的是最新后端代码 |
| 浏览器不弹「保存密码」 | 预期行为，Chrome 不允许扩展页面使用密码管理器；登录态本身会保留 |
| 点图标没反应 | 到扩展管理页确认扩展已启用；Service Worker 异常时点该扩展卡片上的「检查」查看日志 |
| 想修改后端地址 | 目前在扩展管理页移除后重新加载、再填一次即可；或在扩展页面的开发者控制台执行 `localStorage.removeItem('visiontrans_ext_api_base')` 后刷新 |

## 七、实现位置（给开发同学）

| 文件 | 作用 |
|---|---|
| `admin-front/extension/manifest.json` | Manifest V3 声明（Chrome/Edge 通用） |
| `admin-front/extension/background.js` | 点击图标 → 新标签页打开 `index.html` |
| `admin-front/scripts/gen-icons.mjs` | 零依赖生成 16/48/128 PNG 图标 |
| `admin-front/vite.config.js` | `--mode extension` 时相对路径打包，输出 `dist-extension/` |
| `admin-front/src/api/extConfig.js` | 扩展形态判断与后端地址存取/规整 |
| `admin-front/src/views/ExtensionSetupView.vue` | 首次配置页 |
| `admin-front/src/router/index.js` | 扩展模式自动切换 hash 路由 |
| 后端 `application.properties` | CORS 放行 `chrome-extension://*` |

普通网页构建（`npm run dev` / `npm run build`）不经过任何扩展分支，行为不受影响。
