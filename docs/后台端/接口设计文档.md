# 后台管理端接口设计文档

> 基于 `adminConsole` 后端工程（`com.gzu.adminconsole.controller` 包）整理。
> 本文按**页面/模块**组织，每个页面仅保留 1–2 个核心接口（取「大盘查询」+「关键写操作」）。
> 商户端（`jingchen` 模块）接口不在本文档范围内。

## 1. 通用约定

### 1.1 基础路径

| 项 | 说明 |
| --- | --- |
| 服务根路径 | `/api`（`admin-console.api.base-path`，缺省 `/api`） |
| 完整地址示例 | `http://<host>:<port>/api/...` |
| 依赖开关 | `admin-console.api.enabled=true`（缺省开启） |

### 1.2 统一响应包装 `Result<T>`

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 状态码（200 成功 / 400 参数错误 / 404 不存在 / 500 内部错误） |
| message | String | 提示信息 |
| data | T | 业务数据（见各接口「输出参数」） |
| timestamp | long | 响应时间戳（毫秒） |

### 1.3 鉴权与角色

| 项 | 说明 |
| --- | --- |
| 令牌请求头 | `X-Auth-Token` |
| 后台角色 | `SUPER_ADMIN`（超级管理员）/ `OPERATIONS`（运营管理员）/ `AUDITOR`（审计员，只读） |
| 免令牌接口 | 登录类：`/auth/login`、`/auth/auto-login`（统一登录，按账号自动识别管理员/商户）、`/auth/captcha`、`/auth/public-key` |

**对应页面**：后台登录页（`admin-front` 登录模块）。

**接口设计**

表 2-1 管理员登录接口设计

| 项 | 内容 |
| --- | --- |
| 接口名称 | 管理员登录 |
| 接口说明 | 校验账号、RSA 加密口令与点击式验证码，签发会话令牌 |
| 实际URL | `/api/auth/login` |
| 请求方式 | POST |
| 权限要求 | 公开 |
| 输入参数 | 见下表 |
| 输出参数 | 见下表 |
| 输入数据格式 | 见下方 |
| 输出数据格式 | 见下方 |
| 参考请求代码 | 见下方 |

**输入参数**

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | String | 是 | 登录账号 |
| password | String | 是 | RSA 加密后的口令密文 |
| captchaId | String | 是 | 验证码挑战 ID |
| captchaClicks | List&lt;Point&gt; | 是 | 按顺序点击坐标（Point: x, y） |

**输出参数**（`data` 类型：`LoginResultVO`）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| data.token | String | 会话令牌 |
| data.profile.id | Long | 管理员 ID |
| data.profile.name | String | 姓名 |
| data.profile.role | String | 角色中文名 |
| data.profile.roleCode | String | 角色编码（SUPER_ADMIN 等） |
| data.profile.group | String | 所属组 |
| data.expireAt | String | 令牌过期时间（展示用） |

**输入数据格式**

```json
{
  "username": "admin",
  "password": "<RSA密文>",
  "captchaId": "c-001",
  "captchaClicks": [{ "x": 120.5, "y": 88.0 }]
}
```

**输出数据格式**

```json
{
  "code": 200,
  "message": "OK",
  "data": {
    "token": "eyJ...",
    "profile": { "id": 1, "name": "超级管理员", "role": "超级管理员", "roleCode": "SUPER_ADMIN", "group": "平台运营组" },
    "expireAt": "2026-09-15 12:00"
  },
  "timestamp": 1760000000000
}
```

**参考请求代码**

```bash
curl -X POST 'http://host:port/api/auth/login' \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"<RSA密文>","captchaId":"c-001","captchaClicks":[{"x":120.5,"y":88.0}]}'
```
